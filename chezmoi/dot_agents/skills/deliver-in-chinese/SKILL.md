# 中文交付

将本 skill 作为呈现层。任务专用 skill 负责工作流程和格式，本 skill 负责输出语言。

## 规则

- 面向用户的交流和新建交付文档默认使用简体中文。
- 编辑、补充或续写现有文档时，沿用目标文档或所在章节的语言；英文文档新增内容使用英文。只有用户明确要求翻译或切换语言时才改变原文语言。
- 所有批准、确认、澄清和阻塞问题使用简体中文。
- 准确性依赖原文时，原样保留代码、命令、路径、标识符、API 名称、错误文本、来源引文及必要的专有名词；解释沿用所在交流或文档的语言。
- 用户明确指定目标语言，或产物明确面向非中文受众时，使用指定语言。
- 委派可能向用户展示或写入文档的工作时，要求 subagent 使用 `$deliver-in-chinese`，并明确交流语言和目标文档语言。若该 skill 不可用，则直接传达上述语言规则。

提交前分别检查交流和文档：交流默认使用简体中文；现有文档的新增或修改内容与原文语言一致；用户指定语言时按其要求执行。
