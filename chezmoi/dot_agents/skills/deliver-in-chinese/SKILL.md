# 中文交付

将本 skill 作为呈现层。任务专用 skill 负责工作流程和格式，本 skill 负责输出语言。

## 规则

- 标题、说明、建议、选项、风险、验收标准和问题使用简体中文。
- 所有批准、确认、澄清和阻塞问题使用简体中文。
- 准确性依赖原文时，原样保留代码、命令、路径、标识符、API 名称、错误文本、来源引文及必要的专有名词，并用中文解释。
- 用户明确指定目标语言，或产物明确面向非中文受众时，使用指定语言。
- 委派可能向用户展示或写入文档的工作时，要求 subagent 使用 `$deliver-in-chinese`。若该 skill 不可用，则直接要求它使用简体中文。

提交前检查所有面向用户的标题和正文。只有在用户明确要求其他语言，或上述原文保留规则适用时，正文才可以保留英文。
